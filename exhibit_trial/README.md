# 试印分析与续印核算

本目录把 `data/` 的离线记录转成两类结论，并明确哪些结论**不能**成立：

1. **按实际发印安排会怎样**（问题一）：按原随机分组的意向效应，
   未知保留在分母里，按场次对和预约分层解释。
2. **如果纯粹换一版可能怎样**（问题二）：只用实际接触、且场次对可比的观测，
   按户聚类、按志愿者分开说明；不把「接触了哪一版」当随机。

核心结论：现有证据不足以据以续印新版。意向效应 +1.6%，按户聚类区间
[-19.0%, +22.6%]；保护层证据只有个位数已知结果；唯一能兑现已通知承诺的
发放方案在不熟悉层的最不利混用情形越过上限。

## 运行

```sh
python3 -m exhibit_trial.report            # 写 report.md 与 report.json
python3 -m unittest discover -s tests      # 27 项口径测试
```

依赖见 `requirements.txt`（numpy / scipy 仅用于区间重抽）。

## 模块

| 文件 | 作用 |
| --- | --- |
| `data.py` | 读取并校验各表，保留场次、分配、印单等引用关系 |
| `observations.py` | 家庭×场次观测框、成功/失败/未知判定、串版与补记合并 |
| `stats.py` | Wilson / Newcombe 区间、按对分层比例差、随机化检验、按户聚类重抽 |
| `effects.py` | 意向效应、口径敏感性、晚到借阅单影响、实接触比较、保护层 |
| `decision.py` | 印务与经营约束、候选发放安排、印单处置、未签印数 |
| `report.py` | 生成 Markdown 报告与 JSON 摘要 |

## 关键口径

- **观测单位**：一个家庭在一场内的首次有效找寻机会；重复补记只计首次。
- **成功 / 失败 / 未知**：窗口内独立找到为成功；先求助或足窗未找到为失败；
  关厅、窗口不足造成的截尾、缺交班结果、有效邀请但无现场记录为未知。
  未知不计零，也不从分母里删除。
- **未实到邀请**：`entered=no` 的家庭直接排除，不作为找错。
- **串版**：现场记录与借阅补记合并判断；第 2 批晚到借阅单只更新接触证据，
  不回改先前的随机分组。
- **保护层**：只用预约时的分层标识；少儿与不熟悉场馆分别评估，
  重叠家庭在需求里去重，不能两层相加。
- **印单**：`approved` 才是已签印量；`notified` 是对外发放承诺，不能撤。
  追加采购按整批起印计费，浪费不能从成本里抹去。
- **相邻**：同厅相邻两场异版时，间隔必须满足 flush；不足即为不可行。

## 已知限制

- 邀请表只覆盖少数家庭（7 户有预约标签），保护层只能在这少数家庭上观察，
  其余家庭无法补标签。
- P2 的 A 场实开 10 分钟、P6 的 A 场关厅，两对不能按同一条件比较，
  实接触比较已整体排除。
- 实际接触比较的点估计为负但区间跨零，只能说明没有看到新版更好的迹象，
  不能证明新版一定更差。
